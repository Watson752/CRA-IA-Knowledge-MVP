# Test-05: Evidence to Recommendation (Post-Fix)

## Question

How does an auditor move from collected evidence to a defensible finding, root cause and recommendation?

## Post-fix answer (vault-supported)

[[Audit Lifecycle Map]], [[Findings and Recommendations Map]], [[Evidence Evaluation]], [[Professional Judgment]], and [[Reasonable Assurance]] support the full chain. [[Finding]] encodes condition ↔ criteria ↔ cause ↔ consequence ↔ recommendation with “do not invent” cause discipline via [[Root Cause Analysis]]. [[Learning Path - Auditor]] and [[Internal Audit Onboarding Path]] include evidence→condition↔criteria before finding elevation.

Management owns corrective action; IA follows up ([[Management Action Plan]], [[Follow-up]], [[Internal Audit Independence]]).

Primary case path: BI tool acquisition vs deployment — [[Internal Audit - Oversight Use and Continuous Improvement of Business Intelligence]].
