# Test-06: Historical Accuracy (2025 Organizational Chart)

## Question

Is the 2025 CRA organizational chart current, and which information in it may now be outdated?

## Answer

**No — not as a whole.** In this vault, the Ministerial Transition **2025** Organization page (page details **2025-09-09**; source note [[99-Sources/source-notes/SRC-CRA-Org-2025]]) is treated as:

- a **usable baseline for public structure and branch mandates**, and
- a **historical public snapshot for named individuals** on the chart.

It is **not** a permanently current directory of who holds which job today. No web browsing was performed for this test; findings use only vault source notes, the public source register, and organization/role notes already in the vault.

### Organizational structure shown in 2025

From [[99-Sources/source-notes/SRC-CRA-Org-2025]] / [[CRA-Organizational-Overview]]:

- **14** headquarters branches
- a [[Corporate Secretariat]]
- **4** regions
- Split: **6 program** + **8 corporate** headquarters branches
- Regions deliver programs via field offices; HQ program branches provide technical/policy support; corporate branches provide corporate services
- Governance roles described: Minister, Board of Management, Commissioner and CEO, Deputy Commissioner, Taxpayers’ Ombudsperson
- Legend: AC, DAC, RAC, ADM, ED/SGC

**Vault treatment:** “stable structure baseline” / still the best complete public branch inventory ([[CRA-Organizational-Overview]]).  
**Caveat from vault:** no newer **complete** public branch chart is recorded as located; structure currency is therefore **assumed from the 2025 baseline**, not re-proven by a later full chart in-vault.

### Branch names shown in 2025

Exact branch-section headings used as canonical vault titles (program and corporate lists in [[CRA-Program-Branches]] / [[CRA-Corporate-Branches]]). Naming variants on the chart (e.g., “Services” / “Verifications” plural labels) are captured as aliases; mandate headings win for canonical titles.

**May be outdated?** Vault does **not** contain a newer official full branch-name inventory that contradicts 2025. Current status of every branch name beyond that baseline is **not independently re-verified** in-vault after 2025-09-09.

### Elements whose current status cannot be verified from the vault

State clearly: **the vault lacks enough current information** to confirm these as of last verified dates:

1. **All headquarters Assistant Commissioners / DACs** named on the 2025 chart (canonical notes: “Not confirmed on a newer official CRA page”).
2. **All Regional Assistant Commissioners** named on the 2025 chart.
3. **Board Chair and directors** as currently sitting (vault tells readers to verify on the Board page; does not assert a current Chair name).
4. Whether the **14-branch / 6+8 / 4-region** structure remains unchanged after 2025-09-09 (no newer complete chart source note).
5. Whether **Corporate Secretariat** leadership names on the chart remain current.
6. Person-specific claims on **legacy `01-Organization/` branch notes** that still present 2025 chart names as “Named leadership” without the canonical “historical only” framing (e.g., Maxime Guénette on legacy SIIB note).

### Why treat the chart as a historical public snapshot

1. **Publication period:** Ministerial Transition **2025** content; page details **2025-09-09** — a dated briefing package, not a live HR system.
2. **Proven person lag already in vault:** Bob Hamilton remains on that Organization page while the Commissioners page (2026-07-23) names Heather Evans effective 2026-07-13 ([[99-Sources/source-notes/SRC-CRA-Org-2025]] reliability notes).
3. **Vault rule:** do not silently rewrite the historical chart; keep chart names under historical office holders; promote to “current” only with a newer official confirmation ([[CRA-Organizational-Overview]] office-holder rule).
4. **Structure ≠ people:** branch mandates and the AC/DAC/RAC legend can remain useful while every named box on the graphic ages.
5. **No complete successor chart in vault:** absence of a newer full chart is itself a reason not to treat 2025 names as evergreen.

## Recommended targeted fixes

Do **not** implement in this test. Suggested later work:

1. Add dedicated source notes: `SRC-CRA-Commissioners` and `SRC-CRA-Minister-Champagne` (or generic minister SRC), and link them from the register’s empty Source note cells.
2. Soften [[99-Sources/source-notes/SRC-CRA-Org-2025]] `source_status` labeling to match org notes (`current-structure-historical-incumbents`) so “current” is not misread for people.
3. Align legacy `01-Organization/*Branch*` leadership lines with canonical “historical snapshot only” wording (or demote to redirect-only).
4. Remove person-name aliases from role notes (keep people under Current/Historical sections only).
5. Add a one-line banner on [[CRA-Organization-Map]]: “2025 chart people = historical; structure/mandates = baseline pending a newer full chart.”
6. When a newer official complete org chart appears, create a new SRC note rather than overwriting SRC-CRA-Org-2025.
