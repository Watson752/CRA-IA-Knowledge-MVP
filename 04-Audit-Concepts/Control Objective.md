A **control objective** states what a specific [[Control]] is meant to achieve relative to a [[Risk]] (e.g., prevent unauthorized access; detect invalid transactions). Design tests ask whether the control, if performed as intended, can meet that objective; operating tests ask whether it did so in the period.
