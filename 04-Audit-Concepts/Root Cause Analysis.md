**Root cause analysis** asks **why** a condition occurred, when supported by [[Evidence]]. [[Finding]]s include cause “when known” / “where practicable.” [[Recommendation]]s should address root cause rather than symptoms.

**Discipline:** do not invent causes the public report does not support. If cause is unknown, say so. Unsupported assumptions are not root causes.
