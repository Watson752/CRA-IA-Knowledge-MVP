**Evidence hierarchy** (teaching scale—not an official CRA rule) compares typical persuasiveness of evidence forms. More items from one weak source do not fix a reliability problem ([[Evidence Reliability]]).

| Form | Typical use | Caveat |
|---|---|---|
| [[Inquiry]] | Understanding | Not standalone OE proof |
| Documents / procedures | Design / intent | May not prove operation |
| System reports / dashboards | Analytics / monitoring | Need lineage, config, definitions |
| [[Audit Logging|Logs]] / trails | Automated detective controls | Must be protected and complete |
| [[Observation (Procedure)]] | Point-in-time | Not full-period OE alone |
| [[Inspection]] of period evidence | OE sampling | Frame/population errors |
| [[Reperformance]] / independent [[Analytics]] | Strong OE | Depends on complete source data |

Always corroborate management representations ([[Evidence]]). No universal numeric threshold for sufficiency ([[Missing Data]]).
