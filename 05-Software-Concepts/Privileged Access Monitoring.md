**Privileged access monitoring** is detective monitoring of privileged use (logons, elevation, admin actions, sensitive data access) with triage and escalation. Distinct from entitlement [[Access Approval]] / [[Periodic Access Review]].

Relies on complete, protected [[Audit Logging]] and timely [[Monitoring and Alerting]]. [[Monitoring and Reporting]] already expects coverage of privileged activity.
