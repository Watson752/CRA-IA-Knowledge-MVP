**Automated input validation** checks inputs against format/range/mandatory rules before acceptance. A common [[Automated Business Rules|automated business rule]] / [[Automated Control]] pattern. Design tests: rule vs [[Criteria]]; OE: rule enabled over period; bypasses via [[Manual Overrides]] must be governed.
