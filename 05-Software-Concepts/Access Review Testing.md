**Access review testing** is the auditor’s procedure set to evaluate design and [[Operating Effectiveness]] of [[Access Approval]] and [[Periodic Access Review]] (and related joiner–mover–leaver controls).

Typical steps: define complete privileged/user population ([[User Access Dataset]], [[Population Completeness]]); sample grants for approval evidence; sample review cycles for reviewer authority, completeness, timeliness, and follow-up removals; compare to employment/role information via [[Joiner-Mover-Leaver]]; use [[Analytics]] for orphans, unused privilege, and SoD conflicts ([[Sampling Risk]]).

An access listing alone is not sufficient—corroborate with tickets, logs, and review packages ([[Evidence]], [[System-Generated Evidence]]). A signed certification package without entitlement examination or executed removals does **not** demonstrate OE.
