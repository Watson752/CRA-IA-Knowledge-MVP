**Privileged access** is elevated technical or administrative capability beyond ordinary end-user permissions (e.g., administrator, DBA, security-admin, break-glass, highly elevated application roles). It is more sensitive because it can change configurations, identities, logs, or large data populations.

Distinct from ordinary user access and from [[Excessive Privileges]] (too much entitlement for a duty) and [[Unauthorized Access]] (use without valid authorization). Include human admins, [[Service Accounts]], and [[Dormant Accounts]] still enabled when scoping populations ([[User Access Dataset]], [[Population Completeness]]).

Path (teaching): Privileged Access → risk → [[Access Approval]] / [[Segregation of Duties]] → [[Periodic Access Review]] / [[Privileged Access Monitoring]] → [[Access Review Testing]] → [[Evidence]].
