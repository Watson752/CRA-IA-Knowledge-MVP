**Reference data** are codes, hierarchies, rates, and lookup values used in joins and calculations. Inaccurate reference data produces systematic [[Incorrect Automated Decisions|incorrect outcomes]] even when transactional feeds are complete. Needs ownership/stewardship ([[Data Owner]], [[Data Governance]]).
