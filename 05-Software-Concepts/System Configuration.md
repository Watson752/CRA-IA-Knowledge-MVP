**System configuration** is the set of parameters, flags, and rule objects that determine runtime behaviour—distinct from source code and from the approved business requirement. Configuration drift can make a well-designed control fail in production.

Test with [[Configuration Review]]; control changes via [[Change Management]] / [[Deployment Approval]]. Public EFMS report does **not** disclose protected configuration details.
