**Service accounts** (non-human / system identities) run batches, integrations, and applications. They often hold standing privilege and shared secrets—high impact if compromised. Scope them in [[Privileged Access]] and [[User Access Dataset]] reviews; assign owners; prefer managed identities / rotation; monitor use ([[Privileged Access Monitoring]]).
