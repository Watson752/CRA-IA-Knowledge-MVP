# PROJECT PLAN — CRA IA Knowledge MVP (Public Sources)

**Status:** MVP baseline complete (2026-07-23)  
**Supersedes:** Any earlier plan requiring entirely synthetic CRA content  
**As of:** 2026-07-23

## Purpose

Build a personal Obsidian knowledge vault for CRA internal-audit learning using **only publicly available official Canadian government information**, plus clearly labelled derived analysis, general professional knowledge, and optional synthetic demonstrations.

This vault is **not** an official CRA product and is **not** endorsed by the CRA.

## Content classes

| Class | Origin | Authoritative | Use |
|-------|--------|---------------|-----|
| A | `official-public-source` | true (for the public claim) | CRA/GoC facts |
| B | `derived-analysis` | false | Cross-domain interpretation |
| C | `general-professional-knowledge` | false | Audit, software, stats concepts |
| D | `synthetic-demonstration` | false | Fictional demos only |

## Minimum public-source baseline

- Current CRA Departmental Plan
- Latest available CRA Departmental Results Report
- Latest available public CRA organizational overview
- CRA Internal Audit and Program Evaluation landing page
- At least five complete published CRA audit or evaluation reports
- At least one CRA public statistical publication
- At least one Treasury Board / OCG audit source
