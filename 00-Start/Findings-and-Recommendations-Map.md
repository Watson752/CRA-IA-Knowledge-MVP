# Findings and Recommendations Map

Explanatory finding model (reports may not use these exact headings):

```text
Condition
→ [[Criteria]]
→ Cause ([[Root Cause Analysis]])
→ Consequence or Risk ([[Consequence or Impact]])
→ [[Recommendation]]
→ [[Management Response]] / [[Management Action Plan]]
→ [[Follow-up]]
```

Elevation gate: [[Evidence]] → [[Audit Observation]] → (may become) [[Finding]] — not every observation/deficiency is reportable.

- [[Finding]] · [[Audit Observation]] · [[Criteria]] · [[Evidence Evaluation]]
- [[Root Cause Analysis]] · [[Consequence or Impact]] · [[Professional Judgment]]
- [[Recommendation]] · [[Management Response]] · [[Management Action Plan]] · [[Management Action Plan Owner]]
- [[Follow-up]] · [[Internal Audit Independence]]

## Discipline

- Do not invent root causes
- Recommendations address causes/risks; management owns action
- Historical findings are period-bound — [[Interpreting Historical Public Audit Findings]]
