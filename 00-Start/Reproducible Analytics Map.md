# Reproducible Analytics Map

## Workpaper path

```text
Analytical objective ([[Audit Objective]] / [[Criteria]])
→ source ([[Source System Data]], [[Data Lineage]])
→ extraction date / [[Assessment Cut-Off Date]]
→ code/query + parameters + versions
→ transforms ([[Data Transformation]]) + [[Inclusion and Exclusion Rules]]
→ retained outputs
→ review / [[Reperformance]]
→ [[Reproducibility]]
→ judge [[Analytical Validity]] separately
```
