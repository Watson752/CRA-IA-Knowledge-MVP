# Audit Lifecycle Map

End-to-end assurance lifecycle for onboarding.

```text
[[Audit Objective]]
→ [[Scope]]
→ [[Criteria]]
→ [[Risk]] / [[Risk Assessment]]
→ [[Control]]
→ [[Control Testing]] / procedure
→ [[Evidence]]
→ [[Evidence Evaluation]] / [[Audit Observation]]
→ [[Finding]]
→ [[Root Cause Analysis]] / [[Consequence or Impact]]
→ [[Recommendation]]
→ [[Management Response]] / [[Management Action Plan]]
→ [[Follow-up]]
```
