# Statistics and Evidence Map

Derived map from analytics/statistics concepts to audit evidence and conclusions.

## Primary path

```text
[[Audit Objective]]
→ [[Audit Population]] / [[Intended Population]]
→ [[Population Completeness]]
→ [[Sample Selection]] or [[Full-Population Analysis]]
→ [[Analytics]] ([[Descriptive Statistics]], [[Outlier Analysis]], [[Trend Analysis]])
→ [[Evidence]] / [[Evidence Reliability]]
→ [[Finding]] / [[Audit Conclusion]]
```

## Parallel data path

```text
[[Source System Data]]
→ [[Data Pipeline]]
→ [[Missing Data]] / [[Selection Bias]]
→ [[Data Quality]]
→ [[Evidence Reliability]]
→ finding strength ([[How Statistical Limitations Affect Audit Conclusions]])
```

## Key distinctions

- [[Statistical Significance]] ≠ [[Operational Significance]] / [[Materiality]]
- [[Reproducibility]] ≠ [[Analytical Validity]]
- [[Retrieved Population]] ≠ [[Intended Population]]
