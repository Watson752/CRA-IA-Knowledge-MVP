# Cross-Domain Audit Map

## Engagement lifecycle (finding path)

```text
[[Audit Objective]]
→ [[Scope]]
→ [[Criteria]]
→ [[Risk]] / [[Risk Assessment]]
→ [[Control]]
→ Procedure ([[Walkthrough]], [[Inspection]], [[Reperformance]], [[Analytics]], …)
→ [[Evidence]]
→ [[Finding]] (only if condition vs criteria supported)
→ [[Recommendation]]
→ [[Management Action Plan]] / [[Management Response]]
→ [[Follow-up]]
```

## Inquiry path (before any finding)

```text
Risk indicator
→ line of inquiry
→ evidence request
→ audit procedure
→ analysis
→ possible observation
```

A risk indicator (e.g., inconsistent results, incomplete monitoring, unclear ownership) is **not** a finding. See [[Grounded-Audit-Inquiry-Guidelines]] and [[Professional Judgment]].
