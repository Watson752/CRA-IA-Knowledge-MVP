## Separation

| Role | Accountability |
|---|---|
| Program / [[Business Process Owner]] | Outcomes and requirements |
| [[System Owner]] | System fitness / config governance |
| [[Technical Support]] / ITB | Build-run-evolve technology—not automatic process ownership |
| [[Data Owner]] | Definitions, quality, permitted use |
| [[Control Ownership]] | Specific control design/operation/monitoring |
| AERB | Independent assurance—not MAP execution |

[[Unclear Accountability]] predicts controls without owners, unapproved changes, and monitoring gaps.

## Official vs case-specific

Branch mandates (ITB, SIIB, Security Branch, AERB) are **official public facts**. Which branch owns a given engagement subject is **case-specific** when a report names OPI/MAP.
