# CRA Program Branches

Official public sources state that **six** headquarters branches centrally organize and provide technical and policy support for the delivery of CRA programs.

## How program branches differ from corporate branches

- **Program branches** organize technical/policy support for CRA programs (tax, benefits, compliance, recourse, legislative interpretation, service/data integration).
- **Corporate branches** provide corporate services (assurance, finance, HR, IT, legal, public affairs, security, digital transformation) — [[CRA-Corporate-Branches]].
- **Regions** deliver programs in the field — [[CRA-Regions]].

**Paired wording for onboarding:** headquarters **program** branches **support** programs nationally; **regions deliver** programs via field offices. Do not invent reporting lines between a region and a specific HQ branch beyond what an official page or public case states.

## Onboarding tip

When a public audit names an OPI or MAP owner, start with the program branch note, then check whether ITB/SIIB/Security/AERB also appear as partners.
