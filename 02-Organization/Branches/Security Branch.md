# Security Branch

## Full name and acronym

- **Full name:** Security Branch
- **Acronym:** Not established as a standard short form in the official public sources used for this vault. Do not invent one.

## Classification

Publicly classified as a **corporate branch** among CRA headquarters branches (Ministerial Transition 2025 Organization page: 6 program / 8 corporate headquarters branches, plus Corporate Secretariat and 4 regions).

## Public mandate

Enables seamless delivery of CRA programs and services by protecting CRA people, information, and assets; ensures security is considered throughout major programs and initiatives; centralizes security functions for coordination, partner collaboration, incident/emergency management, fraud-risk integration, resource focus, and a professional security workforce.

## Main public responsibilities

- Protection of people, information, and assets.
- Centralized security function coordination and incident/emergency management.
- Integrated management of internal and external fraud risks.
- Agency Security Officer leadership.

## Why a new employee should understand it

Security Branch is the public owner for many cyber and internal-fraud control themes. Cyber and EFMS audits name Security Branch as management respondent.
